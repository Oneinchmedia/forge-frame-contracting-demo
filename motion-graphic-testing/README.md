# Motion graphic testing

Exploratory motion work for the One Inch Media brand. Nothing in this folder is part of the Forge & Frame site build; the folder is ignored by the Next.js app.

## one-inch-storyboard.html

Storyboard v2 for **ONE INCH**, a thirty-second brand ident built on the one-inch punch, with a seven-second cutdown.

Open the file in a browser. It is self-contained: ten frames with timing, visual, motion, audio and the AI technique each shot proves; a playable animatic drawn live in canvas (Play, scrub, keyboard, and a Full / Cutdown toggle); the proposed palette and type; brand slots for the real logo, colors, fonts, studio scan and voice; the production stack; IP guardrails; and the decisions left to the owner.

The animatic is a previz, not the generated footage the frames describe. The `assets` folder holds the One Inch Media lockup, derived from the primary logo: a reverse (light on black) version for the animatic, the tagline on its own, and light and dark versions of the full lockup for the page header. Type is matched by stand-in Google faces until the real fonts are supplied.
